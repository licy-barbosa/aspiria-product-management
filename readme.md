Aspiria - CRUD de Productos



Este proyecto es una aplicación sencilla para gestionar productos.

Incluye un backend en .NET y un frontend en Angular.



Tecnologías

* .NET (Web API)
* Angular 21
* Bootstrap



Funcionalidades

* Listar productos
* Crear producto
* Editar producto
* Eliminar producto



Cómo ejecutar

Backend (.NET)

Abrir el proyecto en Visual Studio

Ejecutar la API

Verificar que funcione en Swagger

Frontend (Angular)

Ir a la carpeta del proyecto Angular



Instalar dependencias:



npm install



Ejecutar:

ng serve



Abrir en el navegador:



http://localhost:4200
